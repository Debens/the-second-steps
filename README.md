# Zayto – AI-Powered Tenant Referencing Platform

Zayto is a modern, AI-driven tenant referencing platform designed to streamline the rental application process in real-time. Built for agents, tenants, and support teams, it combines live API checks, smart automation, and robust workflows in a clean, secure interface.

---

## 🚀 Features (Planned)

- 🧠 AI-powered document and data checking
- 🧾 Real-time credit and referencing via third-party APIs
- 🔐 Secure applicant/agent/admin portals
- 🔄 Open Banking + HMRC integrations for employment and income verification
- 🕵️ Fraud detection on documents and ID
- ✍️ Rent Guarantee Insurance module with contract workflows
- 💼 Agent dashboard for application creation and management
- 🧍 Step-by-step applicant onboarding flow
- 📊 Admin interface for escalated reference handling

---
